# Amazon Product Review Sentiment Analysis: LSTM vs BERT

## Project Overview

This project performs sentiment analysis on Amazon Fine Food Reviews using two deep learning approaches:

1. **LSTM (Long Short-Term Memory):** A recurrent neural network trained from scratch.
2. **BERT / DistilBERT:** A pretrained Transformer model fine-tuned for sentiment classification.

The goal is to classify customer reviews into three sentiment categories: Negative, Neutral, and Positive, and compare both models.

## Problem Statement

Customer reviews contain useful information about product quality and customer satisfaction. Manually reading thousands of reviews is time-consuming.

This project uses Natural Language Processing (NLP) and deep learning to automatically identify the sentiment expressed in customer reviews.

## Dataset

**Amazon Fine Food Reviews**

Dataset source: https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews

The dataset contains Amazon food product reviews, including:
- Score: Customer rating from 1 to 5 stars.
- Text: Written customer review.

For this experiment, a balanced sample is selected.

### Sentiment Label Mapping

| Star Rating | Sentiment | Label |
|---|---|---:|
| 1–2 stars | Negative | 0 |
| 3 stars | Neutral | 1 |
| 4–5 stars | Positive | 2 |

The notebook uses 2,000 reviews per class when a GPU is available and 200 reviews per class when running on CPU.

1. Download the Amazon Fine Food Reviews dataset.
2. Explore the dataset and customer ratings.
3. Convert star ratings into three sentiment classes.

## Models

### 1. LSTM

LSTM is a type of Recurrent Neural Network (RNN) that processes text as a sequence of words.

In this project:
- Words are converted into numerical representations.
- An embedding layer learns word representations.
- The LSTM layer learns sequential patterns.
- The output layer predicts one of the three sentiment classes.

### 2. BERT / DistilBERT

BERT is a pretrained Transformer model that understands words using their surrounding context.

The model is fine-tuned on the Amazon review dataset for three-class sentiment classification.

When running without a GPU, the notebook automatically selects DistilBERT, a smaller and lighter pretrained Transformer model.

## Transfer Learning Experiment

The project compares the models using a smaller labelled training dataset.

This experiment investigates whether pretrained language knowledge helps the Transformer model perform well with less task-specific training data.

The actual accuracy results are generated by the notebook and should be used when discussing the outcome.

## Evaluation Metrics

The following evaluation metrics are used:

- **Accuracy:** Percentage of correctly classified reviews.
- **Precision:** How many reviews predicted as a particular class actually belong to that class.
- **Recall:** How many actual reviews of a class were correctly identified.
- **F1-score:** Harmonic mean of precision and recall.
- **Confusion Matrix:** Shows correct and incorrect predictions for each sentiment class.

The notebook also compares:
- Training time
- Approximate model size
- Number of model parameters
- Prediction time per review

## Deployment Constraints

Some challenges when deploying these models in real applications include:

- Transformer models require more memory.
- Larger models can increase prediction latency.
- GPU infrastructure can increase deployment costs.
- Sarcasm and complex language can affect sentiment predictions.
- Customer language and product domains may change over time.

Possible optimization approaches include quantization, pruning, batching, and using smaller models such as DistilBERT.

## Conclusion

This project demonstrates how deep learning and transfer learning can be applied to customer review sentiment analysis.

LSTM provides a baseline trained from scratch, while BERT-family models use pretrained language knowledge and fine-tuning.

The comparison helps investigate the trade-offs between prediction performance, training time, model size, and deployment requirements.
